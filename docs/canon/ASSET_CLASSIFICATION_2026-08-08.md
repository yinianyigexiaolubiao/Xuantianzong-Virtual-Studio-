## 2. TECH_CONTROL — 当前工程必须继承

### A1 — 总平面与高程控制

作用：50m 级世界坐标、九峰骨架、高程、山脊连续性、古道、九段玄阶、玄天峰、后山、水系、山门和双阙剑尺度。

关键规则：
- 世界包络 8km × 12km；Z 使用绝对海拔。
- 八座地面峰通过山脊、鞍部和谷地形成两条连续山系，禁止独立圆锥。
- 西链：天剑峰 → 镇岳峰 → 天工峰 → 灵兽峰。
- 东链：寒渊峰 → 紫微峰 → 丹霞峰 → 万木峰。
- 玄天峰是唯一大型悬浮主峰。
- 中央主轴顺山势回折，最大连续直视约 250m；禁止笔直通天梯。

### B1 — 九峰功能与关键资产布局

作用：10m 级功能布局、人口、建筑覆盖率、中央资产、交通和空域。

关键规则：
- 九峰不是九座城市；正式建筑低密度分散。
- 山体、林谷、岩脊、水系和修炼空地必须占主体。
- 玄天峰正式建筑覆盖目标 10–12%，绝对上限 15%。
- 生产空间可以使用木、竹、铜、铁、陶、玄石等真实功能材质，不得全宗无差别白玉化。

### C1 — 视觉与高阶神兽出镜控制

作用：所有静态图、无人机、手机、视频与资产设计的正式视觉总则。

最高视觉总纲：
> 宏伟巨大、洁白神圣、仙气充盈、视觉冲击极强；同时服从修仙世界逻辑。

关键规则：
- S 级：玄天峰/玄天殿；祖兽仅在明确专题或护宗场景中可成为 S 级主体。
- A 级：玄岳关、双阙剑、九峰主山体、四级古兽、三神木。
- 宏伟来自山体体量、纵深、高差、遮挡和留白，不来自宫殿密集堆砌。
- 双阙剑保留大型资产冰蓝光特权；禁止全宗泛蓝。
- 洁白不等于全山纯白；山岩、森林、草坡和土壤保留真实自然色。

### E1 — V12 固定相机与视线控制

作用：固定战略母图相机、构图锚点、遮挡和可见性；**不等于真实 DJI 航线**。

关键规则：
- E1 虚拟相机约 (0.00km, 3.33km, 695m)。
- 50mm 等效，三幅 -24°/0°/+24° 横向拼接，总水平视场约 68°。
- 玄天峰为终极中心；玄岳关 + 双阙剑为前景 A 级锚点。
- 至少六座地面峰具有独立轮廓；八峰必须接地，左右山系连续。
- 玄天峰倒悬下缘应大部可见，禁止读成薄盘。
- 真实 DJI 继续使用 24–35mm 等效和真实飞行轨迹。

### F1 — 三维灰模与比例控制

状态：历史文件名为“总确认稿”，但它的技术原则是当前 Digital Twin 必须继承的重要工程依据。

作用：把 V1.6.1 + A1 + B1 + C1 + E1 放进同一三维坐标系验证体量、遮挡和比例。

关键规则：
- 1 单位 = 1m；Z 使用绝对海拔。
- 100m 规则网格用于全宗体量级灰模；后续局部再深化到 10m/1m。
- 八座地面峰必须通过**连续地形网格**表达。
- 中央谷地必须存在，道路与水系通过谷地，禁止人工笔直峡谷。
- 北部必须有地根背脊和伏渊岭体量，承担后山遮挡。
- 玄天峰约 1.45km × 1.05km，400–470m 厚重倒悬包络；禁止圆盘、薄板、UFO 读法。
- B1 建筑在灰模期只使用外包络块体，验证“山大于殿、自然大于人工”。
- 灰模验收看比例、遮挡与构图，不看最终仙气或材质。

### G1 — 正式母图生成控制

当前作用：**未来正式母图阶段使用，不提前用于改变 Digital Twin 几何。**

锁定规则包括：
- 玄天峰保持悬浮倒悬结构。
- 玄天殿为第一视觉主体。
- 不得为了构图移动或缩放已锁资产。
- AI 不得自行新增大型地标。
- 正式母图通过前进行构图、尺度、神兽三重验收。

## 7. 当前工程结论

V0.1 已证明 `Canon → JSON → Blender → Render → MP4` 工程链成立，但其平板地形、规则圆锥山峰和玄天峰圆盘读法未达到 F1/C1/E1 的空间视觉要求。

因此 V0.2 必须被定义为：

**继承 F1 的连续山系与厚重倒悬峰体原则，对玄岳关局部进行 Mini Spatial Proof；不是从零重新设计地形。**
