## 3. TECH_CONTROL — 当前工程必须继承

### A1 — 总平面与高程

- 8×12km；绝对海拔。
- 八座地面峰以山脊/鞍部/谷地连接成两条连续山系，禁止独立圆锥。
- 西链：天剑峰 → 镇岳峰 → 天工峰 → 灵兽峰。
- 东链：寒渊峰 → 紫微峰 → 丹霞峰 → 万木峰。
- 玄天峰唯一大型悬浮主峰。
- 主轴顺山势回折，最大连续直视约250m。

### B1 — 九峰功能与关键资产布局

- 九峰不是九座城市；建筑低密度分散。
- 山体/林谷/岩脊/水系占主体。
- 玄天峰建筑覆盖目标10–12%，上限15%。
- 生产空间允许木、竹、铜、铁、陶、玄石等功能材料；禁止全宗无差别白玉化。

### C1 — 视觉与影像控制

最高标准：宏伟巨大、洁白神圣、仙气充盈、视觉冲击极强，同时服从修仙世界逻辑。

- S：玄天峰/玄天殿。
- A：玄岳关、双阙剑、九峰主山体、四级古兽、三神木。
- 宏伟主要来自体量、纵深、高差、遮挡和留白。
- 双阙剑拥有大型资产冰蓝光特权；禁止全宗泛蓝。
