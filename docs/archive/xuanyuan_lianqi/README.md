## Book-design decisions recovered from the project

The final intended visual language was repeatedly refined toward:

- ancient stitched-book / aged-paper appearance;
- vertical Chinese typesetting;
- no punctuation in the reference-standard edition;
- consistent typeface/column spacing;
- no text touching the ruled lines or frame;
- no repeated page headings by mistake;
- page edges and rules must remain clean and legible;
- `气` / `炁` and related terminology must be globally proofread for intended usage rather than casually mixed;
- output should look like one coherent book, not pages from different templates;
- avoid modern editorial explanations inside the in-world scripture when the requested edition is the pure fictional manual.

## Literary/form structure

The recovered preferred text presents a nine-volume / eighty-one-section style tradition and uses layered in-world textual forms such as:

- 正文
- 歌诀
- 祖师按
- 藏经阁旧批 / 旧批
- 戒语
- 验候
- 篇末小语

The remembered core formulation includes:

`身为玄炉，心为真火。息为橐籥，神为枢纽。炁来不夺，炁去不追。清者可留，浊者当归。行之以缓，守之以恒。内外相应，玄元自生。`

## Canon relationship

Current V1.6.1 identifies 《玄元炼气诀》 as the orthodox Qi-refining root method of Xuantianzong and treats the finalized scripture as an independent cultivation-text source for its own domain.

The scripture does **not** override geography, architecture, camera or unrelated world data.
