# 玄天宗真实手机内容 / 弟子口播 Archive

This branch preserves the project's non-cinematic phone-content line.

## Active imaging rules

From C1/E1/current Canon:

- use a phone-main-camera reading around **24–28mm equivalent**;
- preserve real hand-held micro-motion from breathing/steps;
- do not imitate a mechanical cinema stabilizer;
- exposure adjustment, autofocus search, environmental sound pressure and imperfect framing are allowed when motivated;
- a talking disciple should still leave enough background to communicate the sect's scale;
- phone footage is not automatically a movie trailer — the world itself supplies the spectacle;
- high-tier beasts, when legally/safely visible, should be distant/partial/incidentally encountered rather than posed like pets.

## Recovered content formats

C1 formalized several phone-content types:

1. 弟子口播介绍 — chest/half-body framing, one giant sect asset retained in background.
2. 山门打卡 / 入宗记录 — selfie or companion view followed by camera turn toward Xuanyue Gate/Twin Swords.
3. 偶遇高阶神兽 — environmental reaction first, then incomplete/distant beast view.
4. 峰内工作记录 — herb garden, beast yard, forging, teaching and other real work processes.
5. 祖兽专题许可拍摄 — fixed safe point or distant telephoto with people as scale references.

## 五蕴测灵石 phone-introduction branch

A dedicated project conversation developed an **outer-disciple phone introduction of the spirit-testing stone**.

Locked conversational intent:

- opening should sound like a real creator/disciple talking to viewers, not a formal documentary narrator;
- preferred opening direction: **“兄弟们，今天给你们介绍一下……”**;
- phone-camera realism takes priority over cinematic polish;
- the scene must obey the actual testing system and the current visual scale of the asset;
- avoid unexplained queueing, random crowds or uniformly gray/black clothing.

The exact historical script was not recovered as a standalone File Library text file, so this archive preserves the approved content direction rather than inventing a fake verbatim transcript.

## Spirit-testing Canon context

The historical world-bible lineage consistently defined a three-stage testing system. The first stage uses 五蕴测灵石 at the reception/testing area; later stages review meridians/dantian/hidden root traits and then combine one-year cultivation records with peak selection.

Old visual iterations showed the testing-stone scene and generated explicit user feedback that the stone had been too small, crowd/queue logic looked wrong and disciple clothes were too gray/black. Those images remain historical visual evidence only.
